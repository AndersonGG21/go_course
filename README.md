# Curso de Go

## Descripción
Este repositorio contiene todos los ejercicios y proyectos desarrollados durante mi aprendizaje del lenguaje de programación Go. Cada directorio representa un tema o concepto diferente explorado durante el curso.

## Estructura del Proyecto
El proyecto está organizado en diferentes carpetas, cada una enfocada en un tema específico del lenguaje Go:

- **Conceptos Básicos**: Sintaxis, tipos de datos, variables y constantes
- **Estructuras de Control**: Condicionales y bucles
- **Funciones**: Declaración, parámetros, retornos y funciones anónimas
- **Estructuras de Datos**: Arrays, slices, maps y structs
- **Concurrencia**: Goroutines y channels
- **Interfaces**: Implementación y uso de interfaces
- **Manejo de Errores**: Patrones y mejores prácticas
- **Testing**: Pruebas unitarias y benchmarks

## Requisitos
- Go 1.22.6 o superior
- Editor de código (GoLand, VSCode, etc.)

## Instalación
```shell script
git clone https://github.com/AndersonGG21/go_course.git
cd go_course
```

## Uso
Cada directorio contiene ejemplos independientes que puedes ejecutar con:

```shell script
go run <directorio>/main.go
```
